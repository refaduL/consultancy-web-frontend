# Consultancy Web Client

## Overview
This is the frontend client for the Consultancy Web application, built with modern web technologies.

## Repository
Remote git repo: https://github.com/refaduL/consultancy-web-frontend.git

## Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation
```bash
git clone https://github.com/refaduL/consultancy-web-frontend.git
cd consultancy-web-frontend
npm install
```

### Running the Application
```bash
npm start
```

The application will be available at `http://localhost:3000`

### Building for Production
```bash
npm run build
```
